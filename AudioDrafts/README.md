# CROSSION 음악 시안

이 폴더의 두 WAV는 이 프로젝트를 위해 새로 구성한 절차적 합성 악기 음악 시안입니다. 전용 음악 생성 모델이나 실제 악기 녹음을 사용한 것은 아닙니다.

- Confluence: 로비용, 72 BPM, 약 107초. 패드·잔잔한 발현음·종소리 중심.
- Rift Table: 대전용, 90 BPM, 약 85초. 같은 음색과 조성을 공유하며 부드러운 리듬 추가.
- 48 kHz, 스테레오, 16-bit PCM WAV. 반복 재생용으로 잔향을 시작 부분에 이어 붙였습니다.

외부 음원·녹음 샘플·SoundFont·MIDI·타인의 악보를 가져오지 않았으며, 특정 기존 곡이나 아티스트의 스타일 복제를 지시하지 않았습니다. 작곡 규칙과 합성 방식의 원본은 Tools/Audio/create_crossion_drafts.py에 남겨 두었습니다. 공개 음악 팩의 음원을 이 파일들에 사용한 것도 아닙니다.

프로젝트의 게임·트레일러 등에 활용할 초안으로 제공한 파일입니다. 제3자 샘플 라이선스는 포함되어 있지 않습니다. 다만 독점적 저작권, 기존 모든 음악과의 비유사성, 자동 저작권 탐지 결과를 보장하는 법적 증명서는 아닙니다. 출시 전 실제 청취·게임 내 음량·반복 구간과 필요한 권리 검토를 진행하세요. 음악만 별도로 판매하거나 Content ID에 등록하는 것은 이번 용도를 넘어갑니다.

임시 채택하여 Assets/Audio/Music에 두 WAV를 복사하고 Assets/Prefabs/Audio에 Unity 기본 Audio Source 재생 프리팹을 준비했습니다. 씬 배치는 Unity에서 직접 진행합니다. 상세 절차는 프로젝트 루트의 CROSSION_BGM_SETUP.md를 참고하세요. 실악기풍 상용 OST 마스터가 아닌 합성음 시안이므로 취향에 따라 교체·편곡할 수 있습니다.
